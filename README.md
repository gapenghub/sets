# Sets

Set counter + rest timer + daily routine, as an iPhone home-screen web app.

- **Today** — routine for the weekday, tap an exercise to make it active
- **Sets** — tap anywhere to count a set (and start the rest timer); Undo reverses the whole last tap
- **Timer** — iOS-Clock-style countdown with presets
- Optional **Shortcuts bridge** starts Apple's own timer (Dynamic Island / lock screen) via `shortcuts://run-shortcut`

Single `index.html`, no build step. Data lives in `localStorage`.
